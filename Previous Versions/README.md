# Previous Versions

This folder preserves chapter files as they existed before revisions. Each chapter has its own subfolder, named after its current file without the `.md` extension.

Archived filenames use `<chapter>_<archive-date>_<reason>.md`. The date records when the file was archived, not when its contents were originally written. Preserve archived files unchanged; store subsequent versions under new names. Relative links inside an archived file reflect its original location in `book content` and may need to be resolved from there.
